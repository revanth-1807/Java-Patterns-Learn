GOF DESIGN PATTERNS IN JAVA

This project contains simple Java implementations of all 23 Gang of Four (GoF) Design Patterns.

The patterns are divided into three categories:

1. CREATIONAL PATTERNS

* Singleton
* Factory Method
* Abstract Factory
* Builder
* Prototype

2. STRUCTURAL PATTERNS

* Adapter
* Bridge
* Composite
* Decorator
* Facade
* Flyweight
* Proxy

3. BEHAVIORAL PATTERNS

* Chain of Responsibility
* Command
* Interpreter
* Iterator
* Mediator
* Memento
* Observer
* State
* Template Method
* Visitor
* Strategy

Each pattern is implemented with a simple Java example to understand its core concept, structure, and practical usage.

TECHNOLOGY

* Java
* Object-Oriented Programming
* GoF Design Patterns

PURPOSE
The purpose of this project is to learn and practice Design Patterns in Java and understand how they help create reusable, flexible, and maintainable software.
